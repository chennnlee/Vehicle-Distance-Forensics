# 事前登錄:深度模型 + 虛線長度的尺度錨,與由距離推得的自車速(2026-09-29)

**這份文件在任何結果評分之前 commit**。commit 之後,程式參數與下列規則不再更動;
若必須更動,另開一節寫明「看過什麼之後改的」。

## 1. 要驗證什麼

1. **尺度錨**:單目深度模型 `da3_metric`(DA3METRIC-LARGE,Apache 2.0)給的距離,乘上一個常數 k 變成公尺。
   k 由畫面中的法定虛線決定:沿著虛線量「相鄰兩段虛線起點」的距離(模型單位),與法定週期相比。
   不用時間差、不用地平線公式、不用 SHARP。
2. **由距離推自車速**:虛線畫在地上不動,自車前進時整段虛線的距離一起縮短。
   相隔幾幀的「公尺剖面」往鏡頭方向平移了多少,除以經過的時間,就是自車速。

程式:`tools/depth_dash_scale.py`(方法)、`tools/run_depth_dash_scale.py`(批次規則)。
參數全部在 `depth_dash_scale.PARAMS`,以本文件同一個 commit 為準。

## 2. 沒有用到組員程式

方法程式只 import `cv2`、`numpy` 與 `depth_backends`(深度模型介面,作者 Terry)。
**不 import** `dashcam_range_speed`、`odometer_distance_calib`、`lane_line_fit`、
`auto_odometer_points`、`public_dataset_ego_eval`。車道線與虛線偵測是新寫的
(時間變異量圖 + Hough),不是 `lane_line_fit.py`。

⚠ 物理原理「速度 = 距離變化 ÷ 時間」與「虛線有法定長度」是公共知識,
海盛人工畫格法本身也用虛線當尺。本方法的差別在量法:由深度模型的距離剖面平移量求速度,
不是固定影像列上的閃爍週期。

## 5. 評分定義(事前定死)

1. **海盛自車速**:人工報表的每一段(起訖畫格 a–b,1 起算)對應我方原始影格 a−1 … b−1。
   我方該段速度 = 段內所有「兩幀都在段內」的讀值平均;段內讀值少於一半 → 記為無讀值。
   報 MAE、bias、±3 km/h 內比例、覆蓋率。真值取 `人工` 版報表,不取 AI 版。
2. **comma2k19 距離**:k × `da3_metric` 封存讀值,對雷達(Δ = 0),近場 < 32 m 中位相對誤差,
   配對集與 `docs/DEPTH_MODEL_BENCHMARK.md` §19.3 相同,與該節的「標線常數」並列。
3. **AV2 距離**:k × `da3_metric` 讀值,對光達 3D 框,近場 < 32 m 中位相對誤差。
4. **拒發照登**:品質閘拒發的片列入報表,不從分母拿掉。
