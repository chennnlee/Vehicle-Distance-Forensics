# 開發紀錄:空間版方法 C(`tools/marking_geometry.py`)

只用道路標線幾何量**前車距離**與**自車速**,不用深度模型、不用組員(chennnlee)的程式或方法。
平路:`d = A / (py − y_h)`;`y_h` = 本車道兩條車道線的交點列;`A` = 虛線在 `u = 1/(y − y_h)` 座標上的
**空間週期** `P_u` 換算:`A = L / P_u`(L = 法定週期)。與組員方法 C 的差別:他的 A 來自**時間**
(虛線流過兩條固定列的時間差 × 碼表車速),這裡的 A 來自**單幀裡的空間**(一個法定週期在各距離佔幾列),
不需要車速、不需要固定列、不需要時間週期。

## 第 2 次之後的改動(都有不需要答案的理由,01:03–01:13)

**v3:車道線配對改成「交點與車道寬都要對」**(`track_lines` 在本檔重寫一次迴圈,多保留每個時窗的候選線)。
- 看到的失效(只看影像):hs006 片頭 2–8 s 的被閘時窗,左線正確(分數 ~19),右線卻是車道中間一條
  分數 ~2.5 的假線——`ego_pair` 只挑「離中央最近」,真的右線(分數 ~21)明明在候選裡。
- 規則:平路上所有車道線交於同一消失點,本車道在固定列的像素寬 = 固定公尺 × 固定列,幾乎不變。
  第一輪照原規則挑,取整段的交點中位與車道寬中位;交點偏 > 1.5% 畫面高或寬度偏 > 25% 的時窗,
  改在候選對中挑「跨過畫面中央、交點與寬度都合格、較弱那條分數最高」的一對;都不合格就沒有地平線。
- 結果(不看答案):hs006 保留時窗 40 → **55/56**、A 區塊變動 9.4% → 4.8%、自車速讀值覆蓋 61% → 82%;
  seg21 144 → 149/150。重畫影像確認新挑的線都在真的虛線上。

**沒採用:每條虛線用自己的半高當近端邊緣**(懷疑整段單一門檻讓遠處暗的虛線被切短)。
A 只動 +0.4% / +0.9%,seg21 的「A 隨距離」是 U 形(8–14 m 1343、14–22 m ~1245、22–30 m 1310),
不是地平線偏移該有的單調趨勢(比較像近列鏡頭變形)→ 保留 `depth_dash_scale.dash_cycles` 原樣。

**v4:地平線 = 保留時窗交點列的滑動中位數(±6 個時窗 = ±2.4 s)**。理由(都不看答案):
- 同一台前車相隔 0.1 s 的距離變化:時窗不變時中位 **1.1%**,時窗一換就 **9.4%**(p90 21%)。
  真的俯仰會讓整張影像(含接地點)一起移,`py − y_h` 不變;影像沒跟著動的交點跳動 = 估計雜訊。
- 用「虛線週期彼此多一致」選平滑程度(逐週期 IQR/中位、區塊 bootstrap CI、5 s 區塊 A 的變動):
  hs006 整段固定交點最緊(0.074,逐時窗 0.095),seg21 整段固定反而最差(區塊 A 變動 25%,有真的慢變化),
  ±6 個時窗在兩支都是最好或接近最好 → 取 ±6。
- 結果(不看答案):hs006 A 1647 → **1634**(CI ±1.5%)、逐週期散布 0.095 → 0.073、速度讀值離散 9.4% → 7.7%;
  seg21 左右兩線 A 由 1292 / 1261 變成 1264 / 1264(兩個中位數剛好落在同一個 0.05 格點;
  改用中間 10% 的平均是 1264.4 / 1262.1,差 0.2%),速度讀值離散 6.4% → 4.4%,
  同車 0.1 s 距離跳動(換時窗時)9.4% → 3.6%。
  ⚠ 副作用:seg21 右線 CI 3.08% **剛好沒過 3% 閘**(原本 2.19%),這版 seg21 只用左線;閘不動。
