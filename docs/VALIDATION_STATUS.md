⚠ 界定:
- **驗證的是量法,不是台灣五支 demo 的係數**:這台相機需要的修正接近 1.0(0.92–1.03),沒有測到 0.76 這種大修正;量法精度約 ±4%。
- **安裝差 Δ 未扣**:上表直接拿雷達讀值比,等於假設雷達(保險桿)與相機(擋風玻璃)之間的前向安裝差 Δ = 0。
  Δ 目前沒有獨立依據(Terry 的 benchmark 把 Δ = 0 與 2 m 並列,見 [DEPTH_MODEL_BENCHMARK.md](DEPTH_MODEL_BENCHMARK.md) §15.4、§18.4)。
  Δ 不為 0 時,近場比值與上表的「+3.6% / −1.6%」都會跟著移動;Δ 定案後本節要同步更新。
- 不要把「A 差 1.36 倍」講成「距離差 36%」:A 與 y_h 在有限跨幅下互相交換,可引用的是分距離帶的實測比值。
- 目標絕對速的雷達真值用 CAN 自車速;這台車的 CAN 對 GNSS/INS 位姿低報 1.09%(100 km/h 約 1 km/h,見
  [comma2k19_eval](../data/output/comma2k19_eval/README.md) 4-2-5),所以自車速項 1.94 有一部分可能是 CAN 本身的偏差。
