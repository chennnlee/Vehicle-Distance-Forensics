(此案在 2026-08-02 前從未跑過本專案管線)。1920×1080 @29.888fps,17.93s,536 幀。

(約 1.1s),與碼表的 3s 窗口性質接近;逐秒 GPS 是瞬時值且自帶量化與延遲。
